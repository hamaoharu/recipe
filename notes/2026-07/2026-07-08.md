- いいねボタンから API を呼ぶ設計だけ整理（実装はまだ）

- いいねには2種類ある
  - 自分のいいね（♥ / ♡）→ localStorage / liked state
  - いいね総数（数字）→ API の likes（将来は DB）

- 今の POST /api/roadmaps/[id]/like は likes++ のみ（取り消しはない）
- ボタンでは「未いいね → いいね」のときだけ POST する想定
- 返ってきた likes で roadmaps state を更新し、ハートは引き続き liked を使う

- 一文: ハートは「自分」、数字は「サーバー」。増やすときだけ POST
